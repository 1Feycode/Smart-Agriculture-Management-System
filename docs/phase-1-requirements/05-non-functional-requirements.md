## Firebase-specific implementation notes

- Firestore Security Rules: restrict document access by authenticated UID, role, and ownership; check read/write permissions for farmer, expert, data manager, and administrator collections.
- Firebase Authentication security: enforce email verification, password rules, and secure session handling.
- Firebase Storage upload restrictions: limit file types, file size, and image dimensions; validate uploads before storing them in Storage.
- Secure handling of API keys: store API keys in environment configuration or Firebase Hosting configuration; do not embed secrets in frontend code.
- Firestore indexing and query performance: define indexes for common queries such as market-price lookups, question status views, and report filtering.
- Image compression and upload limits: compress farmer-submitted crop and soil images before storing them.
- Weather API caching: cache external weather responses to reduce repeated requests and protect quota.
- Backup and recovery approach: document role-based backups, restore procedures, and audit-log retention strategy.
- Role-based access control: rely on Firestore rules and controlled role metadata to protect restricted records and administrative actions.
