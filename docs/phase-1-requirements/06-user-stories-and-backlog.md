# 06. User Stories and Backlog

The backlog below is derived from the SRS and prioritized into MVP / Version 1, Phase 2 enhancement, and future enhancement categories.

| Epic | User Story ID | User Story | Related FR IDs | Priority | Sprint / Phase | Acceptance Criteria | Firebase Service |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Authentication and user management | US-01 | As a farmer, I want to register an account so that I can access the system securely. | FR-001, FR-002, FR-003, FR-004 | MVP / Version 1 | Sprint 1 | User can register with valid information; duplicate records are blocked; account is saved and role is assigned. | Firebase Authentication; Firestore user profile collection |
| Authentication and user management | US-02 | As a user, I want to log in and log out securely so that my account remains protected. | FR-005, FR-006, FR-007, FR-011 | MVP / Version 1 | Sprint 1 | User can sign in with credentials; session is protected; logout ends the active session. | Firebase Authentication; route guards |
| Authentication and user management | US-03 | As an administrator, I want to manage accounts and permissions so that access remains secure and aligned with roles. | FR-010, FR-012, FR-120, FR-123 | MVP / Version 1 | Sprint 2 | Admin can activate/deactivate accounts and assign or change roles. | Firestore user roles; admin dashboard |
| Farmer and farm management | US-04 | As a farmer, I want to create and update my profile so that my details remain accurate. | FR-008, FR-014 | MVP / Version 1 | Sprint 2 | Farmer can view and edit personal profile information and save it successfully. | Firestore farmer profile documents |
| Farmer and farm management | US-05 | As a farmer, I want to register one or more farms so that I can connect my activities to the correct location. | FR-015, FR-016, FR-017, FR-020 | MVP / Version 1 | Sprint 2 | Farmer can add farm details and update size, location, and metadata. | Firestore farms collection |
| Farmer and farm management | US-06 | As a farmer, I want to record crop and soil information for my farm so that recommendations are relevant to my conditions. | FR-018, FR-022, FR-037, FR-038, FR-042 | MVP / Version 1 | Sprint 3 | Farmer can add crop and soil records tied to a farm and review them later. | Firestore soil and farm crop collections |
| Crop information | US-07 | As a user, I want to search and view crop information so that I can choose suitable crops and practices. | FR-024, FR-025, FR-026, FR-028, FR-029 | MVP / Version 1 | Sprint 3 | User can search by name and view crop details with conditions and planting guidance. | Firestore crop catalog |
| Crop information | US-08 | As an administrator, I want to maintain crop records so that crop information remains current and reliable. | FR-034, FR-035, FR-036, FR-114 | MVP / Version 1 | Sprint 4 | Admin can add, update, or remove crop records and categories. | Firestore crop collection and admin rules |
| Soil information | US-09 | As a farmer, I want to record soil-test values and sources so that fertilizer guidance uses trusted data. | FR-039, FR-040, FR-041, FR-043, FR-045 | MVP / Version 1 | Sprint 3 | Soil record includes pH, nutrients, type, date, and source; validated values are distinguished from estimates. | Firestore soil test records |
| Soil information | US-10 | As an expert, I want to review soil information so that I can validate advice and reduce risk. | FR-044 | Phase 2 enhancement | Sprint 4 | Expert can access and review relevant soil records for advisory decisions. | Firestore role-based soil access |
| Fertilizer recommendations | US-11 | As a farmer, I want to request fertilizer recommendations so that I can improve crop productivity safely. | FR-046, FR-047, FR-048, FR-049, FR-051 | MVP / Version 1 | Sprint 4 | Farmer can choose farm and crop, submit a request, and see a recommendation workflow. | Firestore recommendation requests and logic |
| Fertilizer recommendations | US-12 | As a farmer, I want to see safe and validated fertilizer guidance so that I can apply it correctly. | FR-050, FR-052, FR-053, FR-054, FR-055, FR-056, FR-057, FR-058 | MVP / Version 1 | Sprint 4 | Recommendation shows fertilizer type, rate, instructions, safety notes, and assumptions. | Recommendation document and rule engine |
| Fertilizer recommendations | US-13 | As an expert, I want to review recommendations so that I can validate and improve the guidance. | FR-059, FR-061, FR-062 | MVP / Version 1 | Sprint 5 | Expert reviews recommendations, marks status, and triggers notifications to the farmer. | Firestore reviews and notifications |
| Weather information | US-14 | As a farmer, I want to view current and forecast weather information for my location so that I can plan field activities. | FR-063, FR-064, FR-065, FR-070, FR-071, FR-072 | MVP / Version 1 | Sprint 3 | User can select a location and see current and forecast weather with update timestamps. | External weather API and cache |
| Weather information | US-15 | As a farmer, I want severe weather alerts so that I can respond to dangerous conditions. | FR-073, FR-074, FR-075 | Phase 2 enhancement | Sprint 5 | System shows alert data when available and clear unavailable-data messages otherwise. | Weather alert integration and notification system |
| Market-price information | US-16 | As a farmer, I want to search and compare market prices so that I can choose the best market for my produce. | FR-076, FR-077, FR-084, FR-085, FR-087, FR-088 | MVP / Version 1 | Sprint 4 | User can search by crop, filter by location, and compare prices across markets. | Firestore market and price collections |
| Market-price information | US-17 | As a data manager, I want to record and verify market prices so that farmers receive trustworthy information. | FR-078, FR-079, FR-080, FR-081, FR-082, FR-083, FR-089, FR-090 | MVP / Version 1 | Sprint 5 | Data manager can add or correct price records with source, unit, and verification status. | Firestore market records and verification logic |
| Expert consultation | US-18 | As a farmer, I want to submit agricultural questions and attach images so that I can receive expert advice. | FR-091, FR-092, FR-093, FR-094, FR-101 | MVP / Version 1 | Sprint 4 | Farmer submits a valid question with category and optional image; status is visible. | Firestore question collection and Firebase Storage |
| Expert consultation | US-19 | As an expert, I want to answer farmer questions and maintain their history so that advice is documented and traceable. | FR-095, FR-096, FR-097, FR-098, FR-099 | MVP / Version 1 | Sprint 5 | Expert replies to assigned questions and the history is retained. | Firestore answer history and role-based Q&A access |
| Notifications | US-20 | As a user, I want to receive and manage notifications so that I stay informed of important system updates. | FR-102, FR-103, FR-107, FR-108, FR-109 | MVP / Version 1 | Sprint 5 | User receives relevant notifications and can view or mark them as read. | Firestore notification collection and UI inbox |
| Administration and reporting | US-21 | As an administrator, I want a dashboard to monitor activity and important records so that I can manage the system effectively. | FR-110, FR-121, FR-131 | MVP / Version 1 | Sprint 5 | Dashboard presents overview metrics and recent activity. | Firestore aggregate queries and dashboard UI |
| Administration and reporting | US-22 | As an administrator, I want to generate reports so that I can review system usage and data quality. | FR-119, FR-124, FR-126, FR-127, FR-128, FR-129, FR-130 | MVP / Version 1 | Sprint 6 | Admin can filter by date and export relevant reports. | Firestore query/report logic and export features |
| Administration and reporting | US-23 | As an administrator, I want to manage crop, fertilizer, and public content so that the system remains accurate and trusted. | FR-114, FR-115, FR-116, FR-122 | Phase 2 enhancement | Sprint 6 | Admin can update content and ensure public agricultural records are maintained. | Firestore content collections and admin governance |
| Authentication and user management | US-24 | As a user, I want password recovery so that I can regain access if I forget my credentials. | FR-009 | Phase 2 enhancement | Sprint 2 | User can request and complete a password reset flow. | Firebase Authentication reset flow |
| Notifications | US-25 | As a farmer, I want weather alerts and market update notifications so that I can react to timely information. | FR-105, FR-106 | Phase 2 enhancement | Sprint 5 | System notifies the user when relevant weather or market events change. | Notifications engine and external triggers |
| Farmer and farm management | US-26 | As a farmer, I want a recommendation history so that I can compare advice over time and refine decisions. | FR-060 | Future enhancement | Phase 3 | Previous recommendations remain accessible and linked to the farm and date. | Firestore recommendation history |
| Expert consultation | US-27 | As a farmer, I want feedback on expert answers so that I can improve the quality of advice. | FR-100 | Future enhancement | Phase 3 | User can provide feedback and the system stores it for review. | Firestore feedback collection |
| Administration and reporting | US-28 | As an administrator, I want to monitor additional agriculture services and future modules so that the system can evolve safely. | NFR-038, NFR-044 | Future enhancement | Phase 3 | New roles and services can be introduced without breaking the current platform. | Role and module extension strategy |
